# Code of Conduct

## Our pledge

We want participation in S.A.N.E Linux to be free from harassment for
everyone, regardless of experience level, gender, identity, background or
technology choices.

## Expected behavior

- Be respectful and constructive; criticize the code or the idea, not the person.
- Assume good intent, ask clarifying questions before rejecting a proposal.
- Give credit for others' work and accept feedback gracefully.
- Keep discussions on-topic and respect the project's small-maintainer capacity:
  a response may take a few days.

## Unacceptable behavior

- Harassment, insults, personal attacks, or discriminatory language.
- Publishing someone else's private information without permission.
- Trolling, deliberate disruption, or repeated unwanted contact.
- Pushing security issues into public issues instead of the private channel in
  [SECURITY.md](SECURITY.md).

## Scope

This applies to repository issues, pull requests, discussions, code reviews,
and any project space where community members interact.

## Enforcement

Maintainers may warn, edit or remove content, close threads, or block accounts.
Report unacceptable behavior privately to `ryuzarza@gmail.com` with enough
context to act. Reports are handled confidentially; repeated or severe
behavior can result in a permanent ban.
